# wwu-csci247-sisa-support README

This is a simple extension meant to add syntax highlighting to .aci files relating to SISA assembly for CSCI247 at Western Washington University.

## Installation
This will only be published on github, thus installation is as such:

1. Go to the [releases tab](https://github.com/TristanCanDev/wwu-csci247-sisa-support/releases)
2. Download the .vsix file
3. Open VSCode
4. Go to the extensions tab
5. Hit the three horizontal dots in the top right corner of the extensions tab next to the reload button
6. Hit install from .vsix
7. Navigate to wherever you downloaded the .vsix file for the extension, select it, and hit 'install'
